# Catálogo de tools — MCP saf-qa

Catálogo público de las herramientas del servidor MCP saf-qa: nombre, descripción y parámetros de cada tool. No contiene credenciales ni ejecuta nada.

- **Página web:** https://anbepa.github.io/mcp-catalog/
- **JSON:** [mcp-catalog.json](mcp-catalog.json)

El catálogo se regenera a diario desde el `tools/list` del servidor.
